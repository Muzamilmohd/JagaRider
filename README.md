# 🏍️ JagaRider

Teman keselamatan untuk penunggang motor (Android 8.0+).

Versi sekarang ialah app asas — fungsi utama akan ditambah dalam versi seterusnya. App ini
**kemas kini sendiri** dari GitHub Releases: semak setiap hari (boleh dimatikan) atau tekan
**Semak kemas kini** dalam app.

## Cara pasang
1. Muat turun fail `JagaRider-v*.apk` dari [Releases](https://github.com/Muzamilmohd/JagaRider/releases/latest).
2. Buka fail tu dan benarkan "Pasang app tidak diketahui" bila diminta.
3. Untuk kemas kini dalam app, benarkan JagaRider memasang app bila diminta.

Privasi: app hanya meminta maklumat release dari `api.github.com` — tiada data pengguna dihantar.
